# M4 real-data baseline validation — 2026-09-13

## Purpose

This record freezes the first Project Fifty strategy validation performed against real Alpaca IEX market data before any autonomous paper order was permitted.

The objective was not to prove profitability. It was to prove that the market-data, historical replay, cost modelling, walk-forward evaluation and autonomous-session components could operate on real data and expose an uneconomic strategy before broker execution was enabled.

## Environment

- Broker/data provider: Alpaca Paper / Alpaca Market Data
- Data feed: IEX
- Timeframe: 5-minute bars
- History window: 2026-07-30T12:45:59Z to 2026-09-13T12:45:59Z
- Candidate symbols: AAPL, AMZN, GLD, GOOGL, META, MSFT, NVDA, QQQ, TLT, XLU
- Benchmark-only symbol: SPY
- Starting Project Fifty paper capital envelope: USD 67.6725
- Modelled slippage: 0.10% per execution
- Real paper orders submitted during validation: 0

## Interpretation

The technical M4 gate passed: authenticated read-only Alpaca IEX data was retrieved for all eleven required symbols; historical bars and latest quotes were parsed; the backtest completed; walk-forward evaluation completed; the validation artifact was produced; and no order was submitted.

The trading/economic gate failed decisively. The strategy traded on roughly 85% of decision points and generated costs equal to approximately 44.9% of the experiment's starting capital over the validation period. A strategy with this turnover profile is unsuitable for Project Fifty's tiny capital base even before considering any additional live frictions.

The correct response is not to relax the cost model or permit paper execution anyway. Project Fifty treats this as evidence that the current baseline requires economic hardening.

## Decision

**M4 engineering/data-validation: PASS.**

**Current strategy economic viability: FAIL.**

**Autonomous paper execution remains blocked.**

The next milestone is M5: reduce turnover, introduce explicit no-trade/economic-edge thresholds, improve rebalance persistence and cadence, compare against cash/SPY/simple quantitative baselines, and require materially improved walk-forward economics before the first autonomous paper-trading session is enabled.
